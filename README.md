# 🔧 Useful Commands

```bash
npx create-expo-app@latest
```

### Start Development Server

```bash
npx expo start
```

### Install Dependencies

```bash
npm install
```

### Start React Native Project

```bash
npx react-native start
```

### Run Android

```bash
npx react-native run-android
```
